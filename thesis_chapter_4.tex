\section{Dataset Generation Implementation}

Our dataset generation system is implemented as a modular, extensible framework that supports both template-based and random-walk approaches to create comprehensive NL2SPARQL datasets. This section details the technical implementation of each component, their interactions, and domain-specific adaptations for the university curriculum, legal, and GESIS knowledge graphs.

\subsection{System Architecture Overview}

The dataset generation system consists of five main components that work together to produce high-quality NL2SPARQL datasets:

\begin{enumerate}
    \item \textbf{Knowledge Graph Schema Extractor}: Analyzes the knowledge graph to identify classes, properties, entity examples, and type relationships
    
    \item \textbf{Vector Search Engine}: Provides semantic search capabilities for entity and property matching using Weaviate and sentence embeddings
    
    \item \textbf{Template-Based Generator}: Creates linguistically diverse questions with corresponding SPARQL queries using a discovery-first approach
    
    \item \textbf{Random-Walk Generator}: Discovers structural patterns in the knowledge graph to ensure comprehensive coverage of query patterns
    
    \item \textbf{Post-Processing Pipeline}: Standardizes SPARQL query formats, enhances dataset with LLM-generated content, and prepares final training/testing splits
\end{enumerate}

The implementation follows a modular design pattern where each component is implemented as a separate Python class with well-defined interfaces, enabling flexible combination and domain-specific customization.

\subsection{Query Optimization for Large Knowledge Graphs}
\label{query-optimization}

A critical aspect of our dataset generation implementation is the optimization of SPARQL queries, particularly when working with large knowledge graphs such as GESIS KG. Query performance can significantly impact the efficiency of the dataset generation process, especially during the discovery-first instantiation phase where multiple queries need to be executed to find valid entity-property combinations.

\subsubsection{Triple Pattern Ordering}

We discovered that the order of triple patterns within SPARQL queries can dramatically affect execution time. Consider the following example from our work with the GESIS Knowledge Graph (before modification):

\begin{lstlisting}[language=SPARQL, caption=Original query - execution time: 2.155 seconds]
SELECT ?authorName WHERE {
  ?author schema:name ?authorName .
  ?publication schema:author ?author .
}
GROUP BY ?author ?authorName
ORDER BY DESC(COUNT(?publication))
LIMIT 1
\end{lstlisting}

By simply reordering the triple patterns, we achieved a significant performance improvement:

\begin{lstlisting}[language=SPARQL, caption=Reordered query - execution time: 0.698 seconds]
SELECT ?authorName WHERE {
  ?publication schema:author ?author .
  ?author schema:name ?authorName .
}
GROUP BY ?author ?authorName
ORDER BY DESC(COUNT(?publication))
LIMIT 1
\end{lstlisting}

This performance difference occurs because of how SPARQL query execution engines process the patterns. In the first query, \texttt{?author schema:name ?authorName} instantiates all entities with a name property, including many that aren't actually authors. This creates a large intermediate result set that must then be filtered by the second triple pattern.

In contrast, the reordered query first identifies publications and their authors with \texttt{?publication schema:author ?author}, creating a much smaller intermediate result set of only actual authors, before retrieving their names. This pattern ordering ensures that we don't instantiate unnecessary triples during query execution.

\subsubsection{Query Structure Optimization}

We implemented further optimizations by restructuring queries to minimize redundant operations. For example, we can enhance the previous query by moving the \texttt{schema:name} property retrieval outside of the grouping operation:

\begin{lstlisting}[language=SPARQL, caption=Fully optimized query with nested structure]
PREFIX schema: <https://schema.org/>
PREFIX ns1: <http://example.org/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX lex2kg-o: <https://example.org/lex2kg/ontology/>
PREFIX gesiskg: <https://data.gesis.org/gesiskg/schema/>
SELECT ?authorName WHERE {
  {
    SELECT ?author WHERE {
      ?publication schema:author ?author .
    }
    GROUP BY ?author
    ORDER BY DESC(COUNT(?publication))
    LIMIT 1
  }
  ?author schema:name ?authorName .
}
\end{lstlisting}

This structure ensures that we only retrieve the name for the single author with the largest number of publications, rather than retrieving names for all authors before filtering. This optimization is particularly valuable when working with large knowledge graphs containing millions of entities.

\subsubsection{N-gram Processing Implementation}

We implemented n-gram processing to break down natural language questions into searchable chunks, enabling more effective matching with knowledge graph elements:

\begin{lstlisting}[breaklines=true,language=python, caption=N-gram Processing Implementation, label=code:ngram-processing]
def _preprocess_into_tokens(self, q: str) -> list[str]:
    """
    Preprocess question into tokens using NLTK RegexpTokenizer
    
    Args:
        q (str): Question string
        
    Returns:
        list[str]: List of tokens
    """
    tok_pattern = r"\w+"
    tokenizer = RegexpTokenizer(tok_pattern)
    tokenized = tokenizer.tokenize(q)
    result = []
    for tok in tokenized:
        tok = tok.lower()
        if tok not in self.stopwords:
            result.append(tok)
    return result

def _generate_ngrams(self, tokens: list[str], max_n: int = 3) -> list[str]:
    """
    Generate n-grams from tokens using NLTK
    
    Args:
        tokens (list[str]): List of tokens
        max_n (int): Maximum n-gram size
        
    Returns:
        list[str]: List of n-grams
    """
    result = []
    
    # Generate unigrams, bigrams, and trigrams using NLTK
    for n in range(1, min(max_n + 1, len(tokens) + 1)):
        n_grams = ngrams(tokens, n)
        result.extend([" ".join(ng) for ng in n_grams])
    
    return result
\end{lstlisting}

\subsubsection{Entity and Property Matching}

The entity and property matching system combines n-gram processing with vector search to identify which entities and properties are mentioned in natural language questions:

\begin{lstlisting}[breaklines=true,language=python, caption=Entity and Property Matching Implementation, label=code:entity-property-matching]
def get_related_candidates(
    self,
    q: str,
    property_candidates: list[str] = [],
    threshold: float = 0.6,
    k: int = 5,
) -> dict[str, list[dict]]:
    """
    Get related entity and property candidates using n-grams and vector search
    
    Args:
        q (str): Question string
        property_candidates (list[str]): Additional property candidates
        threshold (float): Similarity threshold
        k (int): Number of results per search
        
    Returns:
        dict[str, list[dict]]: Dictionary with 'entities' and 'properties' lists
    """
    # Generate tokens and n-grams from question
    tokens = self._preprocess_into_tokens(q)
    ngrams = self._generate_ngrams(tokens)
    
    # Initialize result containers
    result = {"entities": [], "properties": []}

    # Search function for entity or property matching
    def search(ngram, search_type, threshold=threshold):
        if search_type == "entities":
            df_res = self.search_entities(ngram, k=k)
        else:
            df_res = self.search_properties(ngram, k=k)
        
        # Filter by threshold and format results
        filtered_results = []
        for _, row in df_res.iterrows():
            if row.get('score', 0) >= threshold:
                filtered_results.append({
                    'short': row.get('short', ''),
                    'label': row.get('label', ''),
                    'score': row.get('score', 0.0)
                })
        
        return search_type, filtered_results

    # Search using n-grams and property candidates
    search_terms = ngrams + property_candidates
    
    for term in search_terms:
        for search_type in result.keys():
            search_result_type, df_res = search(term, search_type)
            if df_res:
                result[search_result_type].extend(df_res)
    
    # Remove duplicates
    for key in result.keys():
        seen = set()
        unique_items = []
        for item in result[key]:
            item_tuple = (item['short'], item['label'])
            if item_tuple not in seen:
                seen.add(item_tuple)
                unique_items.append(item)
        result[key] = unique_items
    
    return result
\end{lstlisting}

This integrated approach for entity and property matching is used by both the template-based and random-walk generators, ensuring consistent matching behavior across the entire system.

\subsubsection{Discovery-First Template Instantiation}

The key innovation in our implementation is the discovery-first approach that guarantees all generated question-SPARQL pairs are valid and executable:

\begin{lstlisting}[breaklines=true,language=python, caption=Discovery-First Template Instantiation, label=code:discovery-first]
def create_discovery_query(self, template, placeholders):
    """
    Create a discovery query that finds valid values for all placeholders
    
    Args:
        template (dict): The template to convert
        placeholders (set): Set of placeholders in the template
        
    Returns:
        str: The discovery query
    """
    # Extract the WHERE clause from the template
    where_match = re.search(r'WHERE\s*{(.*)}', template["sparqlTemplate"], re.DOTALL | re.IGNORECASE)
    if not where_match:
        return None
        
    # Start with SELECT clause including all placeholder variables
    select_vars = set()
    where_patterns = []
    
    # Process each line in the WHERE clause
    where_clause = where_match.group(1).strip()
    for line in where_clause.split('.'):
        line = line.strip()
        if not line:
            continue
            
        # Replace placeholders with variables
        processed_line = line
        for placeholder in placeholders:
            pattern = r'{[\s]*' + re.escape(placeholder) + r'[\s]*}'
            if re.search(pattern, processed_line):
                var_name = f"?{placeholder}"
                processed_line = re.sub(pattern, var_name, processed_line)
                select_vars.add(var_name)
                
                # For entity placeholders, also select label
                if placeholder.startswith('entity'):
                    select_vars.add(f"?{placeholder}Label")
        
        where_patterns.append(processed_line + '.')
    
    # Construct the SELECT and WHERE clauses
    select_clause = "SELECT DISTINCT " + " ".join(sorted(select_vars))
    where_clause = "\n  ".join(where_patterns)
    
    # Add OPTIONAL label patterns for entity placeholders
    optional_patterns = []
    for placeholder in placeholders:
        if placeholder.startswith('entity'):
            optional_patterns.append(f"OPTIONAL {{ ?{placeholder} rdfs:label ?{placeholder}Label . }}")
    
    # Construct the complete discovery query
    discovery_query = f"{select_clause} WHERE {{\n  {where_clause}\n  {' '.join(optional_patterns)}\n}}"
    
    return discovery_query

def instantiate_template_with_discovery(self, template):
    """
    Instantiate a template using the discovery-first approach
    
    Args:
        template (dict): The template to instantiate
        
    Returns:
        dict: The instantiated question and SPARQL query or None if failed
    """
    # Extract placeholders from the template
    placeholders = self.extract_placeholders(template)
    
    # Create a discovery query that includes all placeholders in the SELECT clause
    discovery_query = self.create_discovery_query(template, placeholders)
    
    # Execute the discovery query
    try:
        results = list(self.graph.query(discovery_query))
        
        if not results:
            print(f"No valid combinations found for template: {template['id']}")
            return None
            
        # Randomly select one complete valid combination of values
        selected = random.choice(results)
        
        # Create a mapping of placeholders to their values
        replacements = {}
        
        # Get the variable names from the query
        query_vars = [str(var) for var in self.graph.query(discovery_query).vars]
        
        # Map variable names to their indices
        var_indices = {}
        for i, var_name in enumerate(query_vars):
            if var_name.startswith('?'):
                var_name = var_name[1:]
            var_indices[var_name] = i
        
        # Extract values for each placeholder
        for placeholder in placeholders:
            value_index = var_indices.get(placeholder)
            if value_index is None:
                continue
                
            value = selected[value_index]
            
            # Handle entity placeholders
            if placeholder.startswith('entity'):
                entity_uri = str(value)
                
                # Get label if available
                label_var = f"{placeholder}Label"
                if label_var in var_indices:
                    entity_label = str(selected[var_indices[label_var]])
                else:
                    entity_label = self.extract_label_from_uri(entity_uri)
                
                replacements[placeholder] = {
                    "value": self.shorten_uri(entity_uri),
                    "label": entity_label,
                    "uri": entity_uri
                }
            # Handle value placeholders
            elif placeholder == "value" or placeholder.endswith("Value"):
                value_str = str(value)
                replacements[placeholder] = {
                    "value": value_str,
                    "label": value_str
                }
            # Handle other placeholders
            else:
                replacements[placeholder] = {
                    "value": str(value),
                    "label": str(value)
                }
        
        # Randomly select a question template
        question_template = random.choice(template["questionTemplates"])
        
        # Replace placeholders in question and SPARQL
        question = self.replace_placeholders(question_template, replacements, "label")
        sparql = self.replace_placeholders(template["sparqlTemplate"], replacements, "value")
        
        # Format the SPARQL query
        sparql = self.format_sparql(sparql)
        
        return {"question": question, "sparql": sparql}
        
    except Exception as e:
        print(f"Error executing discovery query: {e}")
        return None
\end{lstlisting}

\subsubsection{Chain of Thoughts Generation}

Our implementation includes the generation of step-by-step reasoning chains that explain the translation from natural language to SPARQL:

\begin{lstlisting}[breaklines=true,language=python, caption=Chain of Thoughts Generation, label=code:chain-of-thoughts]
def generate_chain_of_thoughts(self, question, sparql, template):
    """
    Generate a chain of thoughts explaining how to translate the question to SPARQL
    
    Args:
        question (str): Natural language question
        sparql (str): SPARQL query
        template (dict): Template used to generate the question-query pair
        
    Returns:
        list: List of thought steps
    """
    if "thoughtsTemplate" not in template:
        # Fallback for templates without thoughtsTemplate
        return self.generate_default_thoughts()
    
    # Get the thoughts template
    thoughts_template = template["thoughtsTemplate"]
    
    # Extract entity and property URIs from SPARQL
    entity_uris, property_uris = self._extract_uris_from_sparql(sparql)
    
    # Create mappings for replacement
    all_mappings = self._create_replacement_mappings(entity_uris, property_uris, sparql)
    
    # Replace placeholders in thoughts
    processed_thoughts = []
    for thought in thoughts_template:
        processed_thought = thought
        
        # Replace each placeholder with the appropriate value
        for placeholder, mapping in all_mappings.items():
            pattern = r'\{' + re.escape(placeholder) + r'\}'
            replacement_value = self.get_appropriate_replacement(thought, placeholder, mapping)
            processed_thought = re.sub(pattern, replacement_value, processed_thought)
        
        # Handle special case for the first entity
        if 'entity' in all_mappings and '{entity}' not in processed_thought and '{entity1}' in processed_thought:
            entity_mapping = all_mappings['entity']
            processed_thought = re.sub(r'\{entity1\}', self.get_appropriate_replacement(thought, 'entity1', entity_mapping), processed_thought)
        
        processed_thoughts.append(processed_thought)
    
    return processed_thoughts

def get_appropriate_replacement(self, thought_text, placeholder, mapping):
    """
    Determine whether to use URI or label based on the context in the thought
    """
    # Check context to determine appropriate replacement
    thought_lower = thought_text.lower()
    
    # Contexts where URI/prefixed form is more appropriate
    if any(phrase in thought_lower for phrase in [
        "in the ontology",
        "represents the",
        "ns1:",
        "property '",
        "entity '",
        "via the '",
        "using",
        "through"
    ]):
        return mapping.get('prefixed', mapping.get('uri', mapping.get('label', placeholder)))
    
    # Contexts where label form is more appropriate
    elif any(phrase in thought_lower for phrase in [
        "categorized as",
        "belonging to", 
        "classified as",
        "of the '",
        "as a '",
        "category '",
        "group '",
        "method '",
        "course '"
    ]):
        return mapping.get('label', mapping.get('value', placeholder))
    
    # Default to label for most contexts
    return mapping.get('label', mapping.get('value', placeholder))

def generate_1_property_patterns(self, count=100):
    """
    Generate 1-property patterns using discovery-first approach
    
    Args:
        count (int): Number of patterns to generate
        
    Returns:
        list: Generated patterns
    """
    patterns = []
    
    # Discovery query to find all valid property-entity combinations
    discovery_query = """
        SELECT DISTINCT ?prop ?entity WHERE {
            ?s ?prop ?entity .
            FILTER(STRSTARTS(STR(?prop), "http://example.org/"))
            FILTER(STRSTARTS(STR(?entity), "http://example.org/"))
        }
    """
    
    try:
        # Execute discovery query
        results = list(self.graph.query(discovery_query))
        print(f"Found {len(results)} valid property-entity combinations")
        
        if not results:
            return patterns
        
        # Generate patterns from valid combinations
        attempts = 0
        max_attempts = count * 3
        
        while len(patterns) < count and attempts < max_attempts:
            attempts += 1
            
            # Randomly select a valid combination
            prop, entity = random.choice(results)
            prop_str = self._shorten_uri(prop)
            entity_str = self._shorten_uri(entity)
            
            # Generate both subject and object target patterns
            pattern_type = random.choice(['subject_target', 'object_target'])
            
            if pattern_type == 'subject_target':
                # Pattern: ?target prop fixed_entity
                sparql = f"SELECT ?target WHERE {{ ?target {prop_str} {entity_str} . }}"
                pattern_id = f'1p_subj_{len(patterns)}'
                pattern_type_name = '1_prop_subject_target'
            else:
                # Find a valid subject for this property
                subject_query = f"""
                    SELECT DISTINCT ?subj WHERE {{
                        ?subj <{str(prop)}> <{str(entity)}> .
                    }}
                """
                subject_results = list(self.graph.query(subject_query))
                if not subject_results:
                    continue
                    
                subj = random.choice(subject_results)[0]
                subj_str = self._shorten_uri(subj)
                sparql = f"SELECT ?target WHERE {{ {subj_str} {prop_str} ?target . }}"
                pattern_id = f'1p_obj_{len(patterns)}'
                pattern_type_name = '1_prop_object_target'
            
            # Validate that this pattern has results
            if self._validate_pattern(sparql):
                pattern = {
                    'id': pattern_id,
                    'sparql': self._format_sparql(sparql),
                    'pattern_type': pattern_type_name,
                    'complexity': 'basic',
                    'property': prop_str,
                    'fixed_entity': entity_str if pattern_type == 'subject_target' else subj_str
                }
                patterns.append(pattern)
        
    except Exception as e:
        print(f"Error in 1-property pattern discovery: {e}")
    
    return patterns

\subsubsection{Pattern Variation Generation}

To ensure diversity, we implemented a systematic pattern variation generator that creates multiple variations of each base pattern by reversing triple directions:

\begin{lstlisting}[breaklines=true,language=python, caption=Pattern Variation Generation, label=code:pattern-variations]
def _create_linear_end_pattern(self, data, pattern_index):
    """
    Create linear end pattern from discovery data with variations
    
    Args:
        data: Discovery data with properties and entity
        pattern_index: Index for pattern identification
        
    Returns:
        dict: Pattern information or None if invalid
    """
    prop1, prop2, prop3, entity = data
    
    props_str = [self._shorten_uri(p) for p in [prop1, prop2, prop3]]
    entity_str = self._shorten_uri(entity)
    
    # Generate random variation (8 possibilities using bit manipulation)
    variation = random.randint(0, 7)
    
    pattern_parts = []
    
    # Determine direction of each triple based on bit pattern
    if variation & 1:  # bit 0: reverse first triple
        pattern_parts.append(f"?hidden1 {props_str[0]} {entity_str}")
    else:
        pattern_parts.append(f"{entity_str} {props_str[0]} ?hidden1")
        
    if variation & 2:  # bit 1: reverse second triple
        pattern_parts.append(f"?hidden2 {props_str[1]} ?hidden1")
    else:
        pattern_parts.append(f"?hidden1 {props_str[1]} ?hidden2")
        
    if variation & 4:  # bit 2: reverse third triple
        pattern_parts.append(f"?target {props_str[2]} ?hidden2")
    else:
        pattern_parts.append(f"?hidden2 {props_str[2]} ?target")
        
    pattern = " . ".join(pattern_parts)
    sparql = f"SELECT ?target WHERE {{ {pattern} . }}"
    
    # Validate pattern has results
    if self._validate_pattern(sparql):
        return {
            'id': f'3p_linear_end_{variation}_{pattern_index}',
            'sparql': self._format_sparql(sparql),
            'pattern_type': f'3_prop_linear_end_v{variation+1}',
            'complexity': 'advanced',
            'properties': props_str,
            'fixed_entity': entity_str
        }
    return None

def select_diverse_examples(template_examples, num_examples=3):
    """
    Select diverse examples from template-based generation for context
    
    Args:
        template_examples (list): Examples from template-based generation
        num_examples (int): Number of examples to select
        
    Returns:
        list: Selected diverse examples
    """
    # Group examples by complexity
    complexity_groups = {}
    for example in template_examples:
        complexity = example.get('complexity', 'basic')
        if complexity not in complexity_groups:
            complexity_groups[complexity] = []
        complexity_groups[complexity].append(example)
    
    # Select examples from each complexity group if available
    selected = []
    for complexity in ['basic', 'intermediate', 'advanced']:
        if complexity in complexity_groups and complexity_groups[complexity]:
            selected.append(random.choice(complexity_groups[complexity]))
    
    # If we need more examples, add random ones
    if len(selected) < num_examples:
        remaining = template_examples.copy()
        for example in selected:
            if example in remaining:
                remaining.remove(example)
        
        additional = random.sample(
            remaining, 
            min(num_examples - len(selected), len(remaining))
        )
        selected.extend(additional)
    
    return selected[:num_examples]

def format_examples_for_prompt(examples):
    """
    Format template examples for inclusion in the prompt
    
    Args:
        examples (list): Selected examples from template-based generation
        
    Returns:
        str: Formatted examples for prompt context
    """
    formatted = []
    for i, example in enumerate(examples):
        example_text = f"Example {i+1}:\n"
        example_text += f"Question: {example.get('question', '')}\n"
        example_text += "Reasoning chain:\n"
        
        thoughts = example.get('thoughts', [])
        for thought in thoughts:
            example_text += f"  {thought}\n"
        
        formatted.append(example_text)
    
    return "\n".join(formatted)

def upper_case_sparql(sparql_query):
    """Convert SPARQL keywords to uppercase"""
    keywords = [
        "SELECT", "WHERE", "FILTER", "BIND", "UNION", "ORDER BY", "COUNT", "AS",
        "GROUP BY", "LIMIT", "OFFSET", "DISTINCT", "ASK"
    ]
    
    for keyword in keywords:

    return sparql_query

def replace_uri_with_prefix(sparql_query):
    """Replace URIs in the SPARQL query with prefixed notation"""

    sparql_query = re.sub(r'<http://example\.org/([^>]+)>', r'ns1:\1', sparql_query)
    
    # Replace GESIS KG URIs
    sparql_query = re.sub(r'<http://schema\.org/([^>]+)>', r'schema:\1', sparql_query)
    
    # Replace Legal KG URIs - be careful with slashes in identifiers
    sparql_query = re.sub(r'<https://example\.org/lex2kg/ontology/([^/>]+)>', r'lex2kg-o:\1', sparql_query)
    
    return sparql_query

def format_sparql_query(query):
    """Format a SPARQL query with proper indentation"""
    # Clean up the query
    query = query.strip()
    
    # Format basic query structure with WHERE clause
    if "WHERE" in query and "{" in query and "}" in query:
        before_where, after_where = query.split("WHERE", 1)
        before_where = before_where.strip()
        after_where = after_where.strip()
        
        # Handle the WHERE clause
        opening_brace_index = after_where.find("{")
        closing_brace_index = after_where.rfind("}")
        
        if opening_brace_index != -1 and closing_brace_index != -1:
            # Get content inside braces
            content = after_where[opening_brace_index+1:closing_brace_index].strip()
            
            # Format the content with proper indentation
            indented_content = format_where_content(content)
            
            # Get any clauses after the closing brace
            after_clause = after_where[closing_brace_index+1:].strip()
            formatted_after = format_after_clauses(after_clause)
            
            # Build the formatted query
            formatted_query = f"{before_where}\nWHERE {{\n{indented_content}\n}}"
            
            # Add any remaining clauses
            if formatted_after:
                formatted_query += formatted_after
            
            return formatted_query
    
    # Special case for ASK queries
    if query.startswith("ASK") and "WHERE" in query:
        return format_ask_query(query)
    
    # If we can't format it well, return as is
    return query

def format_where_content(content):
    """Format the content inside a WHERE clause with proper indentation"""
    # Handle empty content
    if not content:
        return ""
    
    formatted_lines = []
    
    # Handle special clauses like FILTER, BIND, UNION
    content = handle_special_clauses(content)
    
    # Split into lines, respecting special clauses
    lines = re.split(r'\s*\.\s*(?![^{]*})', content)
    
    for line in lines:
        line = line.strip()
        if not line:
            continue
        
        # Add a period if it's missing and not a special clause
        if not (line.endswith(".") or line.endswith("}") or "FILTER" in line or "BIND" in line):
            line += " ."
            
        # Handle semicolons (multiple predicates with same subject)
        if ";" in line:
            semicolon_parts = handle_semicolons(line)
            formatted_lines.extend(semicolon_parts)
        else:
            # Regular line with 2-space indentation
            formatted_lines.append("  " + line)
    
    return "\n".join(formatted_lines)

def remove_spaces_before_chars(sparql_query):
    """Remove spaces before ? and . in SPARQL queries"""
    # Remove spaces before ? that has one space before it
    modified_query = re.sub(r'(?<! ) \?', '?', sparql_query)
    # Remove spaces before .
    modified_query = re.sub(r'(?<! ) \.', '.', modified_query)
    
    return modified_query
\end{lstlisting}

def generate_dataset(domain_config, output_prefix, size=200):

        schema,

    )

def build_graph(self):

    workflow = StateGraph(FROGGraphRAGState)

    workflow.add_node("strategy_selection", strategy_selection_node)

    workflow.add_node("sparql_generation", sparql_generation_node)
    workflow.add_node("answer_generation", answer_generation_node)
    workflow.add_node("google_search", google_search_node)

    # Define the flow
    workflow.set_entry_point("translation")
    workflow.add_edge("translation", "entity_extraction")
    workflow.add_edge("entity_extraction", "strategy_selection")
    
    # Add conditional edges for adaptive routing
    workflow.add_conditional_edges(
        "strategy_selection",
        lambda x: x.next,
        {"verbalization": "verbalization", "sparql_generation": "property_generation"}
    )
    
    # Compile the graph
    self.graph = workflow.compile()
\end{lstlisting}

The state graph implementation offers several technical advantages over a linear pipeline:

\begin{enumerate}
    \item \textbf{Conditional Routing}: The \texttt{add\_conditional\_edges} method enables dynamic workflow decisions based on the current state. This allows us to implement adaptive processing paths depending on query complexity and agent outputs.
    
    \item \textbf{Shared State}: All agents operate on a shared \texttt{FROGGraphRAGState} object, which maintains cumulative processing context across the workflow. This eliminates the need for complex data passing between components.
    
    \item \textbf{Modular Component Replacement}: Individual nodes can be replaced or modified without affecting the overall graph structure, enabling easy experimentation with different implementations.
\end{enumerate}

class EntityExtractionNode:

        system_prompt = f"""You are an expert entity and property extractor for {source_name}.

Format as JSON with 'entities' and 'properties' arrays."""

            prompt = f"{system_prompt}\n\n{user_prompt}"

            extracted_data = json.loads(completion)

        state.related_properties = extracted_data.get("properties", [])

def contains_multiple_entities(question):
    """Check if the question has multiple entities"""
    keywords = ["and", "or", "as well as", "both", "along with", "together with"]
    question = question.lower()
    return any(
        f" {keyword} " in question
        or question.startswith(f"{keyword} ")
        or question.endswith(f" {keyword}")
        for keyword in keywords
    )

\subsubsection{Verbalization Node}
The Verbalization Node implements direct property retrieval for simple questions, bypassing the need for SPARQL generation. This node is particularly complex as it handles direct graph traversal and result formatting:

\begin{lstlisting}[breaklines=true,language=python, caption=Verbalization Node Implementation, label=code:verbalization-node]
class VerbalizationNode:
    """Node for retrieving entity information through verbalization"""
    def __init__(self, llm_factory=None, property_retrieval=None):
        self.llm_factory = llm_factory
        self.property_retrieval = property_retrieval
        self.json_pattern = r"```(?:json)?\s*([\s\S]*?)```"
        
        # Initialize a default SPARQL endpoint
        self.api = SPARQLWrapper("https://query.wikidata.org/sparql")
        self.api.setReturnFormat(JSON)
        
        # Get property retrieval factory for different sources
        from ..utils.property_retrieval_factory import get_property_retrieval_factory
        self.property_factory = get_property_retrieval_factory()
        
        # Initialize the LLM provider
        self._llm_provider = self.llm_factory.get_model_for_verbalization()
        
    def __call__(self, state: FROGGraphRAGState) -> FROGGraphRAGState:
        # Update verbalization object based on knowledge source
        knowledge_source = getattr(state, 'knowledge_source', 'wikidata')
        if hasattr(self, 'verbalization'):
            self.verbalization.set_knowledge_source(knowledge_source)
        else:
            # Create verbalization if it doesn't exist
            self.verbalization = WikidataVerbalization(
                model_name="jinaai/jina-embeddings-v3",
                knowledge_source=knowledge_source
            )
        
        # Use appropriate property retrieval based on knowledge source
        current_property_retrieval = self.property_factory.get_property_retriever(
            knowledge_source, 
            df_properties=self.property_retrieval.df_properties if knowledge_source == "wikidata" else None
        )
        
        if not state.extracted_entities:
            state.next = "sparql_generation"
            return state
        
        entity = state.extracted_entities[0]
        retrieved_resources, err = self.get_entities(entity, k=5, source=knowledge_source)
        
        entity_uri = self.get_most_appropriate_entity_uri(
            entity, 
            state.translated_question, 
            retrieved_resources, 
            knowledge_source
        )
        state.entity_uri = entity_uri

        entity_label = "no label found"
        for resource in retrieved_resources:
            if resource.get('uri') == entity_uri:
                entity_label = resource.get('label')
                break
        
        if entity_uri:
            try:
                # Get candidates - do this ONCE only
                candidates, po, sp = self.verbalization.get_list_of_candidates(
                    entity_uri=entity_uri, 
                    entity_label=entity_label,
                    property_retrieval=current_property_retrieval
                )
                
                # Only continue if we have candidates
                if not candidates:
                    state.next = "sparql_generation"
                    return state
                
                # Encode question once
                question_embed = self.verbalization.encode_text([state.translated_question])[0]
                
                # Encode all candidates once
                cands = list(candidates.values())
                passages_embed = self.verbalization.encode_text(cands)
                
                # Compute similarities once
                similarities = self.verbalization.model.similarity(
                    question_embed, 
                    passages_embed
                ).numpy().flatten()
                
                # Get the best property
                best_index = np.argmax(similarities)
                similarity = float(max(similarities))
                best_property = list(candidates.keys())[best_index]
                
                # Extract results for this property
                result = self.verbalization.extract_results_for_property(
                    best_property, 
                    po, 
                    sp, 
                    output_uri=state.output_uri
                )
                
                # Get references if needed
                references = []
                if (getattr(state, 'include_references', True) and 
                    similarity >= 0.6 and result and
                    knowledge_source == 'wikidata'):
                    raw_references = self.verbalization.get_references_for_property(
                        entity_uri, 
                        best_property, 
                        knowledge_source
                    )
                    
                    # Format references
                    for ref in raw_references:
                        formatted_ref = {}
                        if ref.get('refUrl'):
                            formatted_ref['refUrl'] = ref['refUrl']
                        if ref.get('refDate'):
                            formatted_ref['refDate'] = ref['refDate']
                            formatted_ref['formattedRefDate'] = format_reference_date(ref['refDate'])
                        
                        if formatted_ref:
                            references.append(formatted_ref)
                
                # Store results in state
                state.verbalization_result = result
                state.verbalization_similarity = similarity
                state.verbalization_references = references if references else []
                    
                # Determine if verbalization is successful
                if similarity >= 0.6 and result:
                    state.query_result = result
                    
                    # Process the results for the answer
                    context_str = f'The answer to "{state.question}" is: '
                    for c in result[:50]:
                        for k, v in c.items():
                            context_str += f"{k}={v}, "
                    context_str = context_str[:-2] + "."
                    
                    # Add reference information to context if available
                    if references:
                        context_str += "\n\n**Reference sources:**"
                        # Format references for display
                        for ref in references:
                            if ref.get('refUrl'):
                                context_str += f"\n- Source: {ref['refUrl']}"
                            if ref.get('formattedRefDate'):
                                context_str += f"\n- Retrieved on: {ref['formattedRefDate']}"
                    
                    state.context_str = context_str
                    state.next = "answer_generation"
                    state.approach_used = "verbalization"
                    
                    return state
                
            except Exception:
                pass
        
        # Fallback to SPARQL
        state.next = "sparql_generation"
        return state
\end{lstlisting}

The Verbalization Node implements a sophisticated approach that:
\begin{enumerate}
    \item Retrieves candidate entity URIs from the knowledge source API
    \item Uses an LLM to select the most appropriate entity URI based on question context
    \item Fetches all property-object pairs for the selected entity
    \item Computes semantic similarity between property candidates and the question
    \item Selects the highest-similarity property and retrieves its values
    \item Formats the results for direct answer generation, including reference information
\end{enumerate}

This node enables efficient handling of simple questions without requiring SPARQL generation, significantly improving system responsiveness for common query types.

            state.approach_used = "sparql_failed_no_fallback"

    def execute_sparql(self, query, state=None):
        """
        Execute a SPARQL query with retries and error handling
        """
        # Configure SPARQL endpoint based on knowledge source
        knowledge_source = getattr(state, 'knowledge_source', 'wikidata') if state else 'wikidata'
        
        # Get source-aware SPARQL wrapper for the appropriate knowledge source
        source_aware_api = SourceAwareSPARQLWrapper(knowledge_source)
        
        # Execute the query with retries
        max_retries = 3
        retry_count = 0
        
        while retry_count < max_retries:
            try:
                # Execute query using source-aware wrapper
                results, err = source_aware_api.execute_query(query)
                
                if err:
                    retry_count += 1
                    time.sleep(1)  # Wait before retrying
                    continue
                    
                return results, None
                
            except Exception:
                retry_count += 1
                time.sleep(1)  # Wait before retrying
        
        # All retries failed
        return None, "Query execution failed after multiple attempts"
        
    def _enhance_query_with_references(self, query, state):
        """
        Enhance a SPARQL query to include reference information
        """
        # Only enhance if references are requested and supported by the knowledge source
        if not getattr(state, 'include_references', True):
            return query
            
        knowledge_source = getattr(state, 'knowledge_source', 'wikidata')
        kg_metadata = get_knowledge_graph_metadata()
        
        if not kg_metadata.supports_references(knowledge_source):
            return query
        
        # Check if this is a simple SELECT query that we can enhance
        if not query.upper().startswith("SELECT ") or "GROUP BY" in query.upper():
            return query
        
        try:
            # Parse the query to find variables
            select_match = re.search(r'SELECT\s+(.+?)\s+WHERE', query, re.IGNORECASE | re.DOTALL)
            if not select_match:
                return query
                
            # Add reference variables to the SELECT clause
            select_vars = select_match.group(1)
            if "?refUrl" not in select_vars and "?refDate" not in select_vars:
                enhanced_select = select_vars + " ?refUrl ?refDate"
                enhanced_query = query.replace(select_vars, enhanced_select)
            else:
                enhanced_query = query
            
            # Add reference patterns to the WHERE clause
            where_match = re.search(r'WHERE\s*{(.+)}', enhanced_query, re.IGNORECASE | re.DOTALL)
            if not where_match:
                return query
                
            where_clause = where_match.group(1)
            reference_patterns = """
  OPTIONAL {
    ?statement prov:wasDerivedFrom ?ref .
    OPTIONAL { ?ref pr:P854 ?refUrl . }
    OPTIONAL { ?ref pr:P813 ?refDate . }
  }
"""
            # Add reference patterns before the closing brace
            enhanced_where = where_clause + reference_patterns
            enhanced_query = enhanced_query.replace(where_clause, enhanced_where)
            
            return enhanced_query
            
        except Exception as e:
            # If any error occurs during enhancement, return the original query
            return query

    \item \textbf{Retry Threshold}: Controls how many SPARQL generation attempts are made

These settings can be controlled through the frontend interface, allowing users to customize the system's behavior based on their specific requirements. The settings are stored in a shared state object that flows through the entire processing pipeline, ensuring consistent behavior across all components.

\section{Visualization and Logging System}
The visualization and logging system represents a critical component of our FROGGraphRAG framework, enabling comprehensive analysis of the multi-agent execution process through semantic logging and real-time visualization. This section details the technical implementation of our visualization architecture, focusing on two key aspects: RDF-based logging for semantic analysis and real-time process visualization.

\subsection{RDF-Based Logging Architecture}
To enable advanced semantic analysis of agent execution patterns, we implemented a sophisticated RDF-based logging system that captures detailed execution traces in a machine-readable, queryable format. The system follows the SLOGERT (Semantic Log Event Rule Templates) approach, which transforms execution logs into a knowledge graph using standardized ontologies.

\subsubsection{LogToRDF Converter Implementation}
The core of our RDF-based logging is the \texttt{LogToRDF} class, which transforms execution logs into structured RDF triples. We defined custom namespaces for representing log events, components, and execution metadata:

\begin{lstlisting}[language=python, caption=LogToRDF namespace definitions, label=code:log-to-rdf-namespaces]
def __init__(self, run_id=None, approach_used=None):

The converter transforms each log event into a set of RDF triples that represent the execution process, including entities, queries, parameters, and results. The implementation handles sophisticated semantic patterns for representing various types of events:

\begin{lstlisting}[language=python, caption=LogToRDF event conversion method, label=code:log-to-rdf-events]
def add_log_event(self, log_entry):
    """Convert a single log entry to RDF triples with sophisticated patterns"""
    event_id = self.generate_event_id(log_entry)
    event_uri = self.LOGS_NS[f"Event_{event_id}"]
    
    # Add event type and basic properties
    self.graph.add((event_uri, RDF.type, self.LOG.Event))
    # Add reference to the run metadata entity (foreign key)
    self.graph.add((event_uri, self.LOGEX.belongsToRun, self.metadata_uri))
    
    # Add timestamp
    timestamp = datetime.fromisoformat(log_entry['timestamp'])
    self.graph.add((event_uri, self.LOG.time, Literal(timestamp, datatype=XSD.dateTime)))
    
    # Add component as process/service
    component = log_entry['component']
    self.graph.add((event_uri, self.LOG.pname, self.LOGID[f"{component.replace(' ', '_')}"]))
    
    # Add event type
    event_type = log_entry['event_type']
    event_type_uri = self.LOGID[f"EventType_{event_type.replace(' ', '_')}"]
    self.graph.add((event_uri, self.LOG.eventType, event_type_uri))
    
    # Process event details with sophisticated patterns
    if log_entry.get('details'):
        self._process_details(event_uri, log_entry['details'], event_id)
    
    # Add duration if available
    if log_entry.get('start_time') and log_entry.get('end_time'):
        start = datetime.fromisoformat(log_entry['start_time'])
        end = datetime.fromisoformat(log_entry['end_time'])
        duration = (end - start).total_seconds()
        self.graph.add((event_uri, self.LOG.duration, Literal(duration, datatype=XSD.float)))
\end{lstlisting}

\subsubsection{RDF Schema Design}
Our RDF schema design follows the W3C PROV Ontology for representing provenance information, combined with custom extensions for agent-specific execution patterns. The schema includes:

\begin{itemize}
    \item \textbf{Event Entities}: Representing individual execution events in the agent workflow
    \item \textbf{Process Nodes}: Representing the specialized agent nodes (Translation, Entity Extraction, etc.)
    \item \textbf{Properties and Parameters}: Capturing the inputs and outputs of each processing step
    \item \textbf{Execution Metadata}: Including timestamps, durations, and approach information
    \item \textbf{Entities and References}: Tracking Wikidata entities and properties referenced during execution
\end{itemize}

This schema design enables sophisticated querying and analysis of execution patterns, component performance, and knowledge graph usage.

\subsubsection{JenaUploader Implementation}
To enable persistent storage and querying of execution logs, we implemented a \texttt{JenaUploader} class that uploads the RDF data to an Apache Jena Fuseki server:

\begin{lstlisting}[language=python, caption=JenaUploader implementation, label=code:jena-uploader]
class JenaUploader:
    """Class for uploading TTL data to Apache Jena Fuseki server"""
    
    def __init__(self, base_url=None, dataset_name="visualization-logs"):
        # Get the base URL from environment variable or use default
        self.base_url = base_url or os.environ.get("APACHE_JENA_URL", "http://localhost:3030")
        self.dataset_name = dataset_name
        
        # Ensure base_url has no trailing slash
        if self.base_url.endswith('/'):
            self.base_url = self.base_url[:-1]
    
    def create_dataset_if_not_exists(self):
        """Check if dataset exists, create it if not"""
        try:
            # First check if the dataset already exists
            response = requests.get(f"{self.base_url}/$/datasets")
            if response.status_code == 200:
                datasets = response.json().get("datasets", [])
                dataset_uris = [d.get("ds.name") for d in datasets]
                
                # Check if our dataset is in the list
                if f"/{self.dataset_name}" in dataset_uris:
                    return True
            
            # Dataset doesn't exist, create it
            headers = {"Content-Type": "application/x-www-form-urlencoded"}
            response = requests.post(
                f"{self.base_url}/$/datasets",
                headers=headers,
                data=f"dbName={self.dataset_name}&dbType=tdb2"
            )
            
            return response.status_code in [200, 201, 204]
                
        except Exception as e:
            return False
    
    def upload_ttl(self, ttl_content, graph_name=None):
        """Upload TTL content to Jena Fuseki server"""
        try:
            # Ensure dataset exists
            if not self.create_dataset_if_not_exists():
                return False
            
            # Prepare the endpoint URL
            if graph_name:
                # Upload to specific named graph
                encoded_graph = requests.utils.quote(graph_name)
                url = f"{self.base_url}/{self.dataset_name}/data?graph={encoded_graph}"
            else:
                # Upload to default graph
                url = f"{self.base_url}/{self.dataset_name}/data"
            
            # Upload the TTL content
            headers = {"Content-Type": "text/turtle"}
            response = requests.post(url, headers=headers, data=ttl_content.encode('utf-8'))
            
            return response.status_code in [200, 201, 204]
                
        except Exception as e:
            return False
\end{lstlisting}

def log_event(self, component, event_type, details=None, start_time=None, end_time=None):
    """Log a process event with timestamp"""
    if self.verbose < 1:
        return
        
    timestamp = datetime.now()
    log_entry = {
        "component": component,
        "event_type": event_type,
        "details": details,
        "timestamp": timestamp.isoformat(),
        "start_time": start_time.isoformat() if start_time else None,
        "end_time": end_time.isoformat() if end_time else None
    }
    
    self.logs.append(log_entry)
    
    # If debug_callback is provided, send the log entry through it
    if self.debug_callback:
        debug_msg = f"{component} - {event_type}"
        if details:
            debug_msg += f"\nDetails: {json.dumps(details, cls=CustomEncoder, indent=2)}"
        
        if start_time and end_time:
            duration = (end_time - start_time).total_seconds()
            debug_msg += f"\nDuration: {duration:.3f}s"
        
        # Handle asynchronous callbacks
        if asyncio.iscoroutinefunction(self.debug_callback):
            try:
                loop = asyncio.get_event_loop()
                if loop.is_running():
                    future = asyncio.run_coroutine_threadsafe(self.debug_callback(debug_msg), loop)
                    # Optionally wait for result with timeout
                    try:
                        future.result(timeout=1.0)
                    except Exception as e:
                        print(f"Error in async callback: {e}")
                else:
                    loop.run_until_complete(self.debug_callback(debug_msg))
            except RuntimeError:
                # No event loop in this thread, create a new one
                loop = asyncio.new_event_loop()
                asyncio.set_event_loop(loop)
                loop.run_until_complete(self.debug_callback(debug_msg))
        else:
            # Regular synchronous callback
            try:
                self.debug_callback(debug_msg)
            except Exception as e:
                print(f"Error in callback: {e}")

def save_mermaid_diagram(self):

    components = {}
    for log in self.logs:
        comp = log["component"]
        if comp not in components:
            components[comp] = []
        components[comp].append(log)
    
    # Node counter for unique IDs
    node_counter = {'count': 0}
    
    # Create subgraphs for each component with proper background color
    components_list = list(components.keys())
    
    for comp_name in components:
        node_id = re.sub(r'\s+', '', comp_name)
        shape = self.shapes.get(comp_name, self.shapes["default"])
        color = self.colors.get(comp_name, self.colors["default"])

        mermaid_code.append(f"    subgraph {node_id}_subgraph [\"{comp_name}`\"]")
        mermaid_code.append(f"        style {node_id}_subgraph fill:{color},stroke:#333,stroke-width:3px,font-weight:bold,color:#444")

        events = sorted(components[comp_name], key=lambda x: x["timestamp"])

        for i, event in enumerate(events):

            event_type = event["event_type"]

                event_text = f"{event_type.capitalize()} at {datetime.fromisoformat(event['timestamp']).strftime('%H:%M:%S.%f')[:-3]}"
                if event_type == "end" and event["start_time"] and event["end_time"]:
                    start_dt = datetime.fromisoformat(event["start_time"])
                    end_dt = datetime.fromisoformat(event["end_time"])
                    duration = (end_dt - start_dt).total_seconds()
                    event_text += f" (Duration: {duration:.3f}s)"
                mermaid_code.append(f"        {event_id}[\"{event_text}\"]")
                mermaid_code.append(f"        style {event_id} fill:#f0f0f0,stroke:#666,stroke-width:2px,stroke-dasharray: 5 5,color:#444")
            else:
                # Other event types
                mermaid_code.append(f"        {event_id}[\"{event_type} at {datetime.fromisoformat(event['timestamp']).strftime('%H:%M:%S.%f')[:-3]}\"]")
                mermaid_code.append(f"        style {event_id} fill:white,stroke:#444,stroke-width:2px,color:#444")
            
            # Add details if available
            if event["details"]:
                detail_id = f"{event_id}_details"
                
                # Format the details for display in a single box
                if isinstance(event["details"], (dict, list)):
                    # Format nested structures nicely
                    detail_text = self.format_nested_structure(event["details"])
                else:
                    # Simple value details
                    detail_text = self.sanitize_for_mermaid(str(event["details"]))
                
                # Create a single box with the formatted content
                mermaid_code.append(f"        {detail_id}[\"`{detail_text}`\"]")
                mermaid_code.append(f"        style {detail_id} fill:#f9f9f9,stroke:#aaa,stroke-width:1px,font-size:12px,text-align:left,color:#444")
                mermaid_code.append(f"        {event_id} -->|\"details\"| {detail_id}")
                # Make the detail arrow black
                mermaid_code.append(f"        linkStyle {node_counter['count']} stroke:#000,stroke-width:1px,fill:none")
                node_counter['count'] += 1
            
            # Connect events in sequence
            if i > 0:
                prev_event_id = f"{node_id}_event_{i-1}"
                mermaid_code.append(f"        {prev_event_id} --> {event_id}")
                # Make the event sequence arrow black
                mermaid_code.append(f"        linkStyle {node_counter['count']} stroke:#000,stroke-width:2px,fill:none")
                node_counter['count'] += 1
        
        mermaid_code.append("    end")

    for i in range(len(components_list) - 1):
        current = re.sub(r'\s+', '', components_list[i])
        next_comp = re.sub(r'\s+', '', components_list[i+1])

        next_events = sorted(components[components_list[i+1]], key=lambda x: x["timestamp"])

            first_event_id = f"{next_comp}_event_0"

            mermaid_code.append(f"    {last_event_id} ==>|\"output\"| {first_event_id}")
            mermaid_code.append(f"    linkStyle {node_counter['count']} stroke:#FFFF00,stroke-width:4px,fill:none")
            node_counter['count'] += 1
    
    # Add overall execution info
    total_duration = (datetime.now() - self.start_time).total_seconds()
    execution_info = f"Total Duration: {total_duration:.3f} seconds"
    if self.approach_used:
        execution_info += f" | Approach: {self.approach_used.title()}"
    
    mermaid_code.append(f'    executionInfo["{execution_info}"]')
    mermaid_code.append(f"    style executionInfo fill:#e8f7e8,stroke:#191,stroke-width:2px,font-weight:bold,color:#444")
    mermaid_code.append(f"    title --> executionInfo")
    mermaid_code.append(f"    linkStyle {node_counter['count']} stroke:#000,stroke-width:2px,fill:none")
        
    # Convert to Mermaid diagram markdown
    mermaid_diagram = "\n".join(mermaid_code)
    
    # Create a temp file and save the Mermaid markdown
    temp_file = tempfile.NamedTemporaryFile(suffix='.mmd', delete=False)
    
    # Create markdown content with mermaid code
    approach_info = f" (Approach: {self.approach_used.title()})" if self.approach_used else ""
    markdown_content = f"""# FROGGraphRAG Process Flow{approach_info}

Question: {self.question}
Generated on: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}

```mermaid
{mermaid_diagram}
```
"""
    
    with open(temp_file.name, 'w', encoding='utf-8') as f:
        f.write(markdown_content)
    
    return temp_file.name
\end{lstlisting}

\subsubsection{Debug Callback System}
To enable real-time feedback during the agent's execution, we implemented a debug callback system that sends event notifications to connected clients. This system is integrated with the Django Channels WebSocket framework:

\begin{lstlisting}[language=python, caption=Debug callback implementation, label=code:debug-callback]
async def debug_callback(self, output):
    """Callback function for agent debugging output with real-time streaming"""
    # Fun emojis for each node type
    node_emojis = {
        "Translation Node": "🌍",
        "Entity Extraction Node": "🕵️",
        "Strategy Selection Node": "🔀",
        "Verbalization Node": "🗣️", 
        "Property Generation Node": "🧩",
        "SPARQL Generation Node": "⚙️",
        "Answer Generation Node": "🎁",
        "Google Search Node": "🔍",
        # Default emoji for any unrecognized nodes
        "default": "🐸"
    }
    
    # Extract the node name from the output if possible
    node_name = None
    for key in node_emojis:
        if key in output:
            node_name = key
            break
    
    # Use the appropriate emoji
    emoji = node_emojis.get(node_name, node_emojis["default"])
    
    # Format the message with the emoji
    decorated_output = f"{emoji} {output}"
    
    # Send immediately without buffering
    try:
        await self.send(text_data=json.dumps({
            'debug': decorated_output,
            'role': 'system',
            'message_id': f"debug_{self.message_counter}",
            'timestamp': time.time()  # Add timestamp for debugging
        }))
        
        # Also send to the group for consistency
        await self.channel_layer.group_send(
            self.room_group_name,
            {
                'type': 'debug_message',
                'message': decorated_output,
                'message_id': f"debug_{self.message_counter}",
                'immediate': True  # Flag for immediate processing
            }
        )
        self.message_counter += 1
        
        # Force flush any potential buffers
        await asyncio.sleep(0)  # Yield control to ensure message is sent
        
    except Exception as e:
        logger.error(f"Error sending debug message: {e}")
\end{lstlisting}

The debug callback system provides real-time feedback about the agent's execution process, allowing users to see exactly what is happening at each step. This is particularly useful for diagnosing issues and understanding the agent's decision-making process.

\subsection{Apache Jena Integration for Semantic Analysis}
The RDF-based logging system is integrated with Apache Jena Fuseki, a semantic web server that enables sophisticated SPARQL querying of execution logs. This integration allows for advanced analysis of execution patterns, component performance, and knowledge graph usage.

\subsubsection{SPARQL Query Examples}
Our Apache Jena integration enables a wide range of analytical queries on the execution logs. Below are some example queries that demonstrate the power of the semantic logging approach:

\begin{lstlisting}[language=sparql, caption=SPARQL query for listing all runs with timestamps, label=code:sparql-runs]
PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX logex: <https://w3id.org/sepses/ns/logex#>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>

SELECT ?run ?startTime ?endTime ?duration ?totalEvents
WHERE {
  ?run rdf:type logex:ConversionMetadata ;
       logex:startTime ?startTime ;
       logex:endTime ?endTime ;
       logex:totalDuration ?duration ;
       logex:totalEvents ?totalEvents .
} 
ORDER BY DESC(?startTime)
\end{lstlisting}

\begin{lstlisting}[language=sparql, caption=SPARQL query for finding runs with specific entities, label=code:sparql-entities]

PREFIX logex: <https://w3id.org/sepses/ns/logex#>

SELECT DISTINCT ?run ?entityLabel ?startTime
WHERE {
  ?event log:hasEntity ?entity .
  ?event logex:belongsToRun ?run .
  ?entity rdfs:label ?entityLabel .
  ?run logex:startTime ?startTime .
  
  # Filter for specific entity (remove or change this filter as needed)
  FILTER(CONTAINS(LCASE(?entityLabel), "ma huateng"))
}

\begin{lstlisting}[language=sparql, caption=SPARQL query for analyzing approach distribution, label=code:sparql-approaches]

\begin{lstlisting}[language=sparql, caption=SPARQL query for calculating average duration by component, label=code:sparql-duration]

PREFIX log: <https://w3id.org/sepses/ns/log#>
PREFIX logid: <https://sepses.ifs.tuwien.ac.at/id/log#>

SELECT ?component (AVG(?duration) as ?avgDuration) (COUNT(?event) as ?count)

  ?event log:pname ?componentUri ;
         log:duration ?duration .
  BIND(STRAFTER(STR(?componentUri), "log#") as ?component)
}
GROUP BY ?component
ORDER BY DESC(?avgDuration)
\end{lstlisting}

\begin{lstlisting}[language=sparql, caption=SPARQL query for finding most common entities, label=code:sparql-common-entities]
